DreamGrid

DreamGrid learns a discrete visual state from RGB grid images, predicts action-conditioned futures, and uses imagined rollouts to choose actions with model predictive control.

Running Planner Episode

This is a completed DreamGrid episode. At each step, the planner encodes the current RGB observation, samples candidate action sequences, imagines their futures with the learned VQ dynamics model, scores them, executes the first action, and replans.

Final Evaluation

The final benchmark uses 100 seeded environments, horizon 24, and 4096 sampled candidate action sequences.

Policy Success Hazard Death Timeout Avg Reward Avg Steps Avg Collisions
Random 0.06 0.50 0.44 -11.67 27.67 6.23
Greedy 0.47 0.00 0.53 3.52 23.98 0.00
VQ-MPC 0.85 0.00 0.15 7.31 13.78 0.57
Oracle 1.00 0.00 0.00 9.64 8.17 0.00

The learned visual model beats random and greedy baselines while remaining below the true shortest-path oracle. Its main remaining failure mode is timeout from inefficient long-horizon planning.

Failure Case

DreamGrid is not perfect. The model usually avoids hazards, but the planner can still choose safe, inefficient paths and hit the episode step limit.
